# SEO 개발 DB 실제 검증 결과

2026-11-28 KST. 사용자가 `.env.local`에 Neon dev 연결 값을 넣었다고 알린 뒤 검증했다. 값 자체는 대화·로그에 출력하지 않았다.

- 설정: PostgreSQL URL 형식, Neon 호스트, 직접 연결, `SEO_TEST_DB_BRANCH=dev`, 로컬 SITE_URL, 검색 차단을 확인. production 실행 환경이 아님을 확인했다. dev 대상 판단은 사용자의 dev 선택 확인에 근거하며 Neon 관리 API로 브랜치 이름을 별도 조회한 것은 아니다.
- 접속 성공. 기존 마이그레이션 9개, 누락은 `0009_amusing_enchantress` 하나였다.
- 과거 SQL 해시 사전 검사는 Windows CRLF 차이로 처음 중단했다. 원문 또는 LF 정규화 해시가 기존 DB 기록과 모두 일치함을 읽기 전용으로 확인한 뒤 진행했다. 기존 SQL 내용을 바꾸거나 기존 마이그레이션을 재적용하지 않았다.
- Neon dev에 `0009_amusing_enchantress` 적용 성공. 마이그레이션 총 10개. 신규 SEO 테이블 3개와 인덱스·제약만 추가했다.
- `npm run seo:dev-smoke` 실DB 시험 통과: 등록 → DB 재조회 → 내용 수정 → 잘못된 전이 거부 → 낡은 버전 충돌 거부 → 수정 완료 → 재검사 대기 → 추가 조치 → 수정 완료 → 재검사 대기 → 해결 완료 → 삭제 확인 없이 삭제 거부 → 소프트 삭제.
- 실행별 고유 actor·제목에 해당하는 가상 시험 행과 활동 기록을 finally에서 정리했다. 기존 계정·일지·콘텐츠는 수정하지 않았다.
- 기존 개발 관리자 계정이 존재하며 2차 인증 등록도 되어 있으나, 로컬 `BETTER_AUTH_SECRET`은 비어 있다. 원래 개발 환경 인증 키를 받기 전에는 기존 계정의 브라우저 로그인/서버 액션 E2E를 통과했다고 주장하지 않는다. 키를 임의 교체하거나 계정을 초기화하지 않았다.
- 3180 포트는 계속 저장 불가 화면 미리보기다. 인증 설정 완료 후 실제 Next 앱을 3101 포트에 실행해 브라우저 동작을 별도로 확인해야 한다.
- 운영 DB·운영 배포·검색엔진 제출·Git push 없음.
