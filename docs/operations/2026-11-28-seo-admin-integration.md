- dev `BETTER_AUTH_SECRET`이 비어 있어 기존 계정의 실제 브라우저 로그인은 대기. 사용자가 원래 키를 `concept-review/app/.env.local`에 직접 설정하겠다고 답했다. 값은 읽어 출력하거나 파일로 복제하지 않는다. 기존 계정/비밀번호/2차 인증/인증 키를 임의 재설정하지 않는다.

- 운영 DB는 접속·변경하지 않았다. 0009가 운영에는 미적용이라는 기존 기록이 있으므로, **운영 배포 전 운영 마이그레이션 상태 확인과 필요한 0009 적용은 별도 승인 후 수행**해야 한다. PR 병합으로 자동 운영 배포되는 환경에서도 이 순서를 먼저 지킨다.
