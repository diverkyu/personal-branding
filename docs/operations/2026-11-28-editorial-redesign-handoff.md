# 전체 홈페이지 리디자인 시안 인수인계

작성일: 2026-11-28 · 상태: **시안 검토용, 운영 반영 전**

규강이 확인한 홈·Story 방향을 Freediving·Tours·Films·About·Contact까지 확장했다. 이번 변경은 그 결과를 저장소에 보관하고 공동개발자가 재현·검토할 수 있게 정리하는 것이다. `app/`, 운영 DB, 관리자 설정, Vercel 환경변수는 바꾸지 않았다.

## 1. 확인할 곳

- **소스·실행 방법:** [전체 시안 README](../phase1/mockup/editorial-2026-11-28/README.md)
- **온라인 시안:** <https://kyu-journal-design-20261128.energizer629.chatgpt.site/> — 소유자 전용이다. 공동개발자에게 접근 권한이 없으면 저장소 파일을 내려받아 실행한다.
- **비교할 운영 사이트:** <https://www.diverkyu.com/>
- **참고한 편집 방향:** <https://blog.kalsenlim.com/category/stories/> — 사진과 글 목록의 비중, 여백, 읽는 흐름을 참고했다. 해당 사이트의 코드·사진·문구는 복사하지 않았다.

시안 원본 기준은 Sites 소스 커밋 `6d6e3e8914fd3602b9ae07e66f4c8ae4e0fd6893`이다. 이 저장소의 보관본에는 외부 링크의 `noreferrer` 보완, 끝줄 공백 정리, 실행 안내·폰트 라이선스 고지를 반영했다. 온라인 시안의 접근 권한이나 배포 버전은 이번 작업에서 바꾸지 않았다.

## 3. 운영 사이트와 구분할 부분

- Story 상세 본문·About 소개 일부는 **구성을 보여 주는 예시**다. 발행 원고나 확정된 경력으로 취급하지 않는다.
- 코론 투어의 날짜·모집 상태는 시안을 만들 때 고정한 표시다. 실제 모집 상태는 운영 CMS에서 다시 확인한다.
- Films는 기존 1~6화를 중심으로 보여 준다. 전체 운영 작품을 대체하는 목록이 아니며, 새로 발행한 작품이 자동 추가되지 않는다.
- Contact는 입력을 서버에 저장하거나 메일을 발송하지 않는다. 메일 앱에서 사람이 내용을 확인하고 보내는 시안이다.
- 메뉴 이동은 `#story`, `#film/ep6` 같은 해시 경로다. 운영 URL·검색 노출·CMS 데이터 연결을 구현한 것이 아니다.
- 장비·후기·여행 추천·관리자·법무 화면 전체는 이번 시안 범위에 포함하지 않았다. 운영 적용 시 기존 기능을 유지해야 한다.
- 하드코딩된 공개 링크·카피·색상은 독립 시안을 위한 것이다. 운영 코드에서는 `SITE_URL`, 사이트 설정, 디자인 토큰 및 데이터 계층을 사용한다.

## 4. 이번에 보완한 사항

1. 세로형 Films 포스터가 대표 작품 영역에서 과하게 잘리지 않도록 전체 이미지가 보이게 조정했다(시안 제작 단계에서 반영).
2. 투어·창작 문의 버튼이 Contact의 해당 유형을 미리 선택하도록 연결했다(시안 제작 단계에서 반영).
3. 저장소 보관 과정에서 일부 외부 새 탭 링크에 `noreferrer`를 추가해 `noopener noreferrer`를 맞췄다.
4. 자체 호스팅 폰트의 라이선스 전문 3개와 리소스 고지를 함께 보관했다.

## 5. 검증 결과와 한계

### 통과

- 시안 제작 단계: 대표 10개 화면을 390 / 768 / 1440px로 확인한 30개 조합에서 가로 넘침, 표시 중인 이미지의 로딩 실패, 중복 표시된 H1이 없었다.
- 시안 제작 단계: 데스크톱·태블릿·모바일 화면을 캡처해 육안 확인했다. **그 캡처 파일은 이 PR에 보관하지 않았다.**
- 시안 제작 단계: Story 필터·검색·빈 결과 초기화·목차, Films 정렬·회차 이동, 모바일 메뉴·Escape·포커스, 문의 필수 입력·유형 선택을 확인했다.
- 시안 제작 단계: 6화의 실제 YouTube 재생을 확인했다(0:02 / 1:30). 화면 이동 중 확인한 범위에서 실행 오류가 없었다.
- 저장소 보관 단계: JavaScript 5개 구문 검사, 정적 리소스 참조 408개와 상대 문서 링크 156개, 원본 156개 파일 비교를 통과했다. 원본과의 차이는 두 파일의 외부 링크 `noreferrer` 보완과 CSS 끝의 빈 줄 정리다. 로컬 정적 HTTP 검사에서 시안 폴더 161개 파일이 모두 200 응답과 동일한 내용을 반환했다. 비밀 파일·생성 파일 제외 여부도 확인했다.

### 실패

- 확인한 범위에서 미해결 실패 없음.

### 미검증

- 실제 휴대폰 기기, 모든 영상의 끝까지 재생, 메일 앱 초안 열기·실제 발송, 서버 접수·CMS 연동.
- 운영 앱의 `npm run check`와 E2E는 이번 문서·독립 시안 보관 변경에서는 실행하지 않았다. `app/` 변경이 없으며 운영 회귀 통과를 주장하지 않는다.
- 현재 운영 화면과 새 시안의 동일 데이터·동일 폭 전후 캡처 비교는 아직 별도 산출물로 만들지 않았다. 실제 운영 적용 PR에서 확보한다.

### 대기

- 규강·Lucia의 화면 구성 및 카피 검토, 적용 범위 결정, 실제 앱 구현 PR.

### 보안 점검(security-guidance)

`security-guidance` 플러그인은 사용하지 않았으며, AGENTS §9.4에 따라 Codex가 직접 검토했다. 시크릿 하드코딩·위험한 주입·경로 조작을 발견하지 못했다. HTML 템플릿은 고정 데이터와 허용한 ID로만 생성하고, 문의 유형은 허용 목록으로 제한한다. 메일 제목·본문은 URI 인코딩하며 영상은 클릭 후 고정 YouTube 도메인과 영상 ID로만 연다. 서버·DB·인증 API가 없는 독립 시안이므로 운영 인증·권한 통제를 검증한 것은 아니다. `.git`, `.openai`, `.env*`, 실행 로그, 중복 빌드 결과는 보관 대상에서 제외했다.
