## 1. 운영자에게 확인한 사실

2024년부터 프리다이빙 강사로 활동. AIDA 마스터 강사(Master Instructor), AIDA 유소년 강사. 강습 지역·자격 취득일·자격 번호는 제공되지 않아 추가하지 않았다. About에 경력·자격을 보이는 문장으로 넣고 같은 정보를 Person에 연결한다.

AI 영상 특강은 **준비 중**이다. 수강 신청·확정 일정·모집 중이라는 표현을 쓰지 않으며 기존 소식 요청·협업 문의 흐름을 유지한다.

공유 이미지는 운영자가 선택한 기존 남색·라임·KYU 로고의 타이포형이다. `app/public/images/kyu-share.png`(1200×630). 실제 작품 포스터나 콘텐츠 대표 이미지가 있으면 그것을 먼저 쓴다.

코론 투어의 확인된 방문 장소는 바라쿠다 호, 깔라윗섬 일대 Dugong Watch 오피스, 디미팍 아일랜드다. 제공된 Coron/Busuanga·Palawan·Philippines를 주소의 지역 단위로 넣었다. 도로명·우편번호·좌표·집결지는 만들지 않았다. 상세 화면에도 같은 방문 지역을 표시한다. 여러 섬에 걸친 투어이며 위치 정밀도와 리치 결과 적격 판정은 별도 확인 대상이다.

### 작품 6편

영상 제목·회차·실제 재생 정보만 근거로 우선 보완했다. **회차별 줄거리·제작 도구·프롬프트·스킬은 운영자 답변 대기**다. 제목에서 내용을 추측해 시놉시스를 만들거나, 없는 제작기를 볼 수 있다고 약속하지 않았다. 검색 설명의 분량을 늘리는 것만으로 콘텐츠 품질이 해결되는 것은 아니다. 실제 줄거리와 제작 노트를 CMS에 넣는 후속 편집이 필요하다.

`config/filmSeo.ts`는 확인한 slug·제목·초기 요약이 일치할 때만 적용되는 편집 기본값이다. CMS에서 새로 쓴 SEO 설명·요약이 우선한다. 5·6화의 자막, 6화의 길이가 바뀌어도 이전 설명을 고집하지 않는다. 향후 회차를 이 파일에 계속 추가하는 방식이 아니라 CMS의 개별 SEO 칸으로 운영한다.

### 코론 투어 상세

- 검색 제목: **2026 코론 프리다이빙 투어** (기존 구체적 제목 유지)
- 설명: “12월 1~5일, 코론에서 듀공 왓칭과 바라쿠다 레이크 프리다이빙을 즐깁니다. 기록보다 여유, 맛있는 식사와 커피챗을 함께하는 여행의 항공편·상세 일정·준비물을 안내합니다.” (기존 설명 유지)
- 현재 화면의 모집 상태는 **마감**이다. 메타에서 모집 중으로 바꾸지 않는다. 마감은 행사 취소가 아니므로 EventCancelled로 표시하지 않는다.
- 실제 대표 사진을 등록하면 OG·Twitter·Event 이미지에 반영된다. 사진이 없는 현재는 OG·Twitter에 브랜드 이미지를 쓰되 Event.image에 로고를 행사 사진처럼 넣지 않는다. **실제 투어 대표 사진은 추가 과제**다.

| 빈 목록이 사이트맵에 남음 | Story 포함 6종 목록의 noindex·사이트맵 정책 일치 | 일반 페이지는 임의로 noindex하지 않음 |
| 작성자 식별이 이름뿐 | Article·VideoObject·주최자를 동일 `/about#person`·About URL로 연결 | 공개 작품의 실제 제작자는 운영자라는 현재 단일 저자 모델. 공동 저자 생기면 CMS 확장 필요 |
| 인물의 자격·경력 부족 | 확인된 AIDA 자격과 2024년 강습 시작을 화면/Person에 반영 | 강습 지역·자격 번호 등 미제공 사실 생략 |
| Event의 장소 주소·참여 방식 | 확인된 장소에 PostalAddress 지역·국가, OfflineEventAttendanceMode, 주최자 URL | 도로명이 없는 섬에 허위 streetAddress를 만들지 않음. Google 리치 결과 별도 확인 |

| h1·언어·상태·404 | 기존 정상 구조 유지, 실제 HTML/E2E 회귀 점검 | 비공개·미존재 상세는 기존 404 유지 |
| 프리뷰·어드민 차단 | 기존 robots 정책·인증·소유 확인 값 보존 | SITE_INDEXING 강제 on은 기존 정책이며 이번 변경에서 사용하지 않음 |
| FAQ·리뷰·지역 SEO | 있는 사실과 원문만 유지 | 질문만 있는 글에 답변을 꾸며 FAQPage를 만들지 않음. 별점·주소·LocalBusiness 추정 금지 |
| 등록·수집·색인 | 기존 등록 작업과 구분 | 이번 코드 변경으로 색인 완료를 선언하지 않음. 배포 후 사이트맵·URL 검사 별도 |
| 자동 점검·IndexNow·llms.txt | 회귀 검증과 읽기 전용 inventory 제공 | 별도 SEO 관리 기능 작업과 중복 구현하지 않음. 주기 실행·키 등록·llms.txt는 이번 범위 밖 |

### 날짜 해석: 감사안 정정

`contents.updatedAt`은 공개 글의 **임시 저장**만 해도 바뀐다. 그대로 lastModified에 쓰면 비공개 초안의 수정 시간을 공개 문서 갱신으로 알리게 된다. 현재 `transitionContent()`는 공개 반영 때 `publishedAt`을 다시 설정하므로 기존 Story·Films·여행 sitemap의 시각은 이미 마지막 공개 반영 시각이다. 장비·투어도 이 값을 전달하도록 맞췄다. 예약 글은 공개 예약 시각을 쓴다. 최초 발행일과 재발행일이 별도로 저장되는 구조는 아니며, 이를 정확히 분리하는 작업은 별도 데이터 모델 과제다. 이번에는 운영 DB나 마이그레이션을 바꾸지 않는다.

## 4. 코드 위치와 유지보수
