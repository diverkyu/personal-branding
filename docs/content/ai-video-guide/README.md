# AI 영상 + 제작 가이드 발행 원고

규강 님이 노션에 쓴 「이런 AI 영상, 어떻게 만드냐고요? 초보자를 위한 제작 가이드」와 영상(릴스)을 사이트에 올리기 위한 **복사해서 붙여넣는 원고**입니다. 노션과 어드민이 연결되는 것이 아니라, 이 원고를 어드민의 입력칸에 직접 넣습니다(실제 어드민 사용 시험을 겸합니다).

## 파일

| 파일 | 용도 |
| --- | --- |
| [story-guide.html](story-guide.html) | **Story 글 본문**. 브라우저로 열고 "본문 전체 선택" → 복사 → 어드민 본문 칸에 붙여넣기. 표·복사 상자·목록·인용이 그대로 들어옵니다 |
| [film-fields.md](film-fields.md) | **Films 작품**의 칸별 입력값, 영상 소개, 제작 노트 3칸(그대로 복사), Story 글의 제목·요약·태그 |

이 원고가 사이트의 한도(글자 수, 표 크기)와 편집기 서식에 맞는지는 시험(`app/src/editor/aiVideoGuideDraft.test.ts`)이 확인합니다. 원고를 고쳤다면 `npm run test`로 다시 확인하세요.

## 올리는 순서

1. **이미지 저장소(Blob) 연결**: 영상 작품은 포스터 이미지가 있어야 발행됩니다. 어드민 > 미디어에서 이미지가 올라가는지 먼저 확인하세요. 안 되면 연결 가이드(INFRASTRUCTURE §6)를 따릅니다.
2. **Story 글 먼저**: 어드민 > 전체 콘텐츠 > 새 글(Story). 제목·요약·주소 이름·태그는 [film-fields.md](film-fields.md) 아래쪽 표대로. 본문은 `story-guide.html`에서 복사해 붙여넣습니다.
   - 본문 안의 `[이미지 자리 …]` 3곳은 이미지 버튼으로 사진을 올려 넣은 뒤 그 줄을 지웁니다(사진이 없으면 줄만 지웁니다). 이미지는 대체 텍스트가 필요합니다.
   - "완성 결과" 아래에서 **영상** 버튼으로 릴스 주소를 넣습니다.
   - 미리보기 → 발행.
3. **Films 작품**: 새 글 > 영상. [film-fields.md](film-fields.md)의 값을 넣고 포스터를 올립니다. 제작 노트 3칸은 글상자의 내용을 그대로 붙여넣습니다. 미리보기 → 발행.
4. 공개 화면(PC·휴대폰)에서 확인합니다. 인스타 영상은 **포스터를 누른 뒤 인스타 화면 안에서 재생 버튼을 한 번 더** 눌러야 하고, 처음 뜰 때 몇 초 걸릴 수 있습니다.

## 노션 원문에서 사이트용으로 바꾼 것

| 노션 | 사이트 |
| --- | --- |
| "댓글로 남겨주세요", "저를 태그해 주세요" | "Contact 화면의 이메일로 보내 주세요" (사이트에는 댓글이 없습니다) |
| "이번 안내서는 제작용 초안입니다 … 첨부하지 않았어요" | 삭제 (초안 안내) |
| "불러오는 중…" (노션 영상 칸) | "완성 결과" 아래에 릴스를 영상 버튼으로 넣기 |
| 💡 설명 상자 | 인용(왼쪽 선이 있는 글) |
| 시간별 행동표, 문제·해결 표 | 표 (그대로) |
| 코드 블록(프롬프트 4개) | 복사 상자 ("복사" 버튼) |
| 체크리스트 | 목록 |
| 노션 제목 | Story 제목 (한 줄, 80자 이내) |

## 규강 님이 확인해 주세요

- [ ] 영상 제목, 요약, 태그(제안)가 괜찮은지
- [ ] 영상에 **한글 자막**이 들어 있는지(자막 있음 체크)
- [ ] 글에 적은 **모델·플랫폼 이름과 버전**(Seedance 2.5, 힉스필드, 뉴테이크)이 지금도 맞는지. 서비스가 바뀌면 글도 낡습니다
- [ ] 프롬프트를 공개해도 되는지(제작 노트의 "프롬프트·스킬" 칸은 비워 두면 보이지 않습니다)
- [ ] "AI 제작" 표기 문구(사이트 설정 > Films)
- [ ] 포스터로 쓸 장면
- 얼굴 이미지는 규강 님 본인 사진이라 확인되었습니다(2026-11-16).
