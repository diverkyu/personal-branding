## 4. 얼마나 보관하고 어떻게 파기하나

운영 원칙(운영자 결정): **최소한의 항목을 최소한의 기간만**. 목적을 이루면 1년이 되기 전이라도 지웁니다.

| 정보 | 보관 기간 | 파기 시점과 방법 | 지금 구현 |
| --- | --- | --- | --- |
| 예약 문의 | **응대가 끝나면 지체 없이, 늦어도 접수일로부터 1년** | 응대 완료(참가 확정 후 투어 종료, 또는 참가하지 않기로 한 때) → 운영자가 어드민에서 **영구 삭제**. 1년이 지나면 **매일 자동 삭제** | 수동 삭제 ○ / 1년 자동 삭제 ○ / **"확정" 상태는 자동 삭제에서 빠짐** ⚠️ |
| 소식 받기 | **안내를 보내면 지체 없이, 늦어도 1년** (철회 시 즉시) | 모집 안내 발송 → 삭제. 1년 자동 삭제 | 수동 ○ / 자동 ○ |
| 운영자 메모 | 그 문의와 함께 | 문의 삭제 시 함께 삭제 | ○ |
| 수강 후기 | 게시하는 동안. 철회 요청 시 즉시 비공개 → 삭제 | 어드민에서 철회·삭제(휴지통 30일 뒤 영구 삭제) | ○ |
| 서버 접속 기록 | Vercel 보관 기간 `[확인]` | Vercel이 삭제 | 운영자가 통제하지 않음 |
| 이메일 문의 | 답변이 끝나면 지체 없이, 늦어도 1년 `[결정]` | 메일함에서 삭제(휴지통 비우기까지) | **수동, 운영자가 지켜야 함** |
| 내보내기 파일(CSV) | 쓰고 바로 | 사용 후 즉시 삭제, 보관하지 않음 | 운영 규칙 |
| 법령상 보존이 필요한 기록 | 해당 법정 기간 | 다른 정보와 **분리 보관** 후 기간 끝나면 파기 | **해당 여부 미정** — 아래 5번 |

**파기 절차** (개인정보 보호법 제21조, 시행령 제16조 원문 확인)
1. 보유기간이 지났거나 목적을 이룬 정보를 고릅니다(자동 삭제는 매일, 수동은 응대 완료 때).
2. 운영자(= 개인정보 보호책임자)가 어드민에서 삭제합니다.
3. 전자 파일은 **복원할 수 없게 영구 삭제**합니다(어드민 삭제는 DB에서 행을 지우며 복구 기능이 없음). 출력물은 파쇄·소각합니다.
4. 다른 법령으로 보존해야 하는 정보는 **분리해서** 보관하고, 기간이 끝나면 같은 방법으로 파기합니다.

⚠️ **처리방침과 실제가 일치해야 합니다**(2026 작성지침이 강조). 현재 코드는 "확정" 예약 문의를 자동 삭제하지 않으므로, ① 법무 검토 결과 보존 의무가 없으면 코드를 고쳐 "확정"도 1년 안에 지우고, ② 보존 의무가 있으면 그 근거·항목·기간을 처리방침에 적고 분리 보관해야 합니다. "응대가 끝나면 지체 없이"는 **운영자가 직접 지워야** 지켜지는 약속입니다.

## 5. 이용약관이 필요한가

| 문서 | 필요한가 | 이유 |
| --- | --- | --- |
| **개인정보 처리방침** | **필요(의무)** | 폼으로 이름·연락처·이메일을 받으므로 개인정보처리자. 개인정보 보호법 제30조, 홈페이지 상시 게재(시행령 제31조 제2항). 미수립·미공개는 과태료 대상 |
| **수집·이용 동의 문구** | 필요(현재 방식 유지 시) | 동의로 받는다면 목적·항목·기간·거부권 4가지 고지(제15조 제2항). 문의 응대는 "계약 체결 과정에서 정보주체 요청에 따른 조치"(제15조 제1항 제4호)로 동의 없이 볼 여지도 있어 **법무 확인** |
| **일반 이용약관** (회원 약관) | **원칙적으로 불필요할 가능성이 큼** | 회원가입·로그인·게시판·결제가 없어 약관으로 맺을 이용계약이 없습니다. 약관 작성을 일반적으로 강제하는 법은 없습니다 |
| **단, 투어를 사이트로 판매한다고 볼 경우** | **필요할 수 있음** | 사이트에 투어 정보를 올리고 신청을 받아 유료로 진행하면 **통신판매**(전자상거래법 제2조 제2호)가 될 수 있습니다. 그러면 사이버몰 운영자로서 상호·대표자·주소·전화·이메일·사업자등록번호·**이용약관**을 표시해야 하고(제10조), 통신판매업 신고(제12조, 고시 기준 이하 면제), 거래 기록 보존(시행령 제6조: 계약·결제 5년, 불만·분쟁 3년, 표시·광고 6개월) 의무가 따를 수 있습니다 |
| 투어 참가·취소·환불 안내 | **유료 투어라면 필요** | 참가비·취소 기준은 신청 전에 보여야 하고, 사실상 거래 약관 역할을 합니다(초안: [CONSENT-AND-TERMS-DRAFT.md](CONSENT-AND-TERMS-DRAFT.md) §2, 수치 빈칸) |
| 사이트 이용 안내(저작권·외부 링크·정보 정확성) | 선택 | 의무는 아니지만 콘텐츠 무단 사용, 여행 정보 면책을 알리려면 짧게 둘 수 있습니다 |

**결론**: "회원가입이 없으니 이용약관은 필요 없다"는 **투어를 사이트에서 판매하지 않는다**는 전제에서만 맞습니다. 사이트로 문의를 받아 유료 투어를 진행하는 구조가 통신판매에 해당하는지가 **법무 검토의 1순위 질문**입니다. 해당한다면 일반 회원 약관이 아니라 "투어 이용약관(참가·취소·환불)"과 사업자 정보 표시가 필요합니다.

## 7. 운영자가 지금 정하거나 해야 할 것

1. 사업자 등록 여부와 투어 대금 수령 방식(→ 통신판매 판단의 기초).
2. 이메일 문의 보관 기간(제안: 답변 후 지체 없이, 최대 1년)과 메일함 정리 습관.
3. 처리방침 공개 연락처(제안: 사이트 연락 이메일과 같은 주소).
4. `CRON_SECRET` 설정 확인(없으면 1년 자동 삭제가 돌지 않음).
5. 법무 검토 결과에 따라: "확정" 예약 자동 삭제 여부(코드), 동의 문구·처리방침 게시, 투어 환불 규정 수치.
