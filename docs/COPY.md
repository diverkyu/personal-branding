## 접근성 문구

| 요소 | 원문 |
| --- | --- |
| Header 홈 로고 aria-label | KYU 홈 |
| nav aria-label | 주요 메뉴 |
| SVG aria-label | 깊은 바닷속으로 내려가는 다이버의 콘셉트 일러스트 |
| 필터 role=group aria-label | 포트폴리오 필터 |

이 문서에는 실제 이력이나 작업 성과를 추가하지 않았습니다. 전체 카피와 콘셉트 표시는 초기 시안 그대로입니다.
