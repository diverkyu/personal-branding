## 글꼴 — SIL Open Font License 1.1

`assets/fonts/`의 WOFF2 파일은 기존 홈페이지 빌드에서 자체 호스팅하던 DM Sans·Noto Sans KR·Lora 파일을 내용 변경 없이 복사한 것입니다. `fonts.css`는 이 폴더의 파일을 읽습니다. 방문 시 외부 글꼴 CDN을 요청하지 않습니다.

## 이미지·영상·콘텐츠

`assets/*.webp`는 사용자가 제공했거나 기존 KYU 홈페이지에 등록한 자료를 이 시안에서 다시 사용한 것입니다. 판타지 이미지, AI 제작 설명 이미지, 코론 포스터, 「찬란한 보통의 날들」 1~6화 포스터가 포함됩니다. 이 파일에 글꼴의 OFL을 적용하지 않으며, 별도의 일반 재배포·상업 이용 허가를 부여하지 않습니다.

YouTube 영상은 사용자 채널의 해당 영상 주소로 연결하거나 클릭한 뒤 플레이어를 불러옵니다. 영상 파일을 이 폴더에 복사하지 않았습니다. YouTube·Instagram은 각각 별도 서비스이며, 이 시안의 라이선스 고지가 해당 서비스의 이용 조건을 대신하지 않습니다.

Story 본문과 일부 소개 문구는 배치와 읽는 흐름을 보여주기 위해 새로 작성한 예시입니다. 운영 글의 원문이나 이미 발행된 콘텐츠로 보지 않습니다.

## 디자인 참고와 코드

[Kalsentic Stories](https://blog.kalsenlim.com/category/stories/)의 이미지 중심 편집 구성을 참고했습니다. 해당 사이트의 코드·사진·글·로고를 복사하지 않았습니다. 이 시안의 HTML·CSS·JavaScript와 단순한 검색·재생 도형은 시안을 위해 작성했으며, 별도 UI 라이브러리·아이콘 패키지·JavaScript 프레임워크를 포함하지 않습니다.
