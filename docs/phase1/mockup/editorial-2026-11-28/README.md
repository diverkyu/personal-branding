# KYU 전체 홈페이지 시안 — 2026-11-28

밝은 배경과 큰 이미지, 글 카드 중심으로 구성한 **검토용 시안**입니다. 홈·Story에서 시작해 프리다이빙·투어·Films·소개·문의와 각 상세 화면까지 확장했습니다.

**운영 반영을 확정한 구현 명세가 아닙니다.** 이 폴더는 독립 실행되는 정적 시안이며, `app/`의 운영 화면·어드민·DB·접수 기능을 바꾸지 않습니다. 일부 글과 소개 문구는 화면 구성을 보여주기 위한 예시입니다.

## 내 컴퓨터에서 보기

별도 패키지 설치, Node.js, DB 연결, `.env` 파일이 필요하지 않습니다. 폴더 전체를 내려받아 `index.html`과 `assets/`의 위치를 유지하세요. GitHub 화면에서 HTML 파일을 클릭하면 소스가 표시됩니다.

1. 저장소를 내려받거나 이 폴더 전체를 복사합니다.
2. `index.html`을 브라우저로 엽니다.
3. 상단 메뉴로 화면을 이동합니다. 브라우저 뒤로 가기·앞으로 가기도 사용할 수 있습니다.

로컬 파일에서 영상이나 클립보드 기능이 제한된다면, Python이 설치된 컴퓨터에서 **저장소 루트**를 기준으로 아래 명령을 실행하세요.

```powershell
cd docs/phase1/mockup/editorial-2026-11-28
python -m http.server 8792 --bind 127.0.0.1
```

브라우저에서 [로컬 시안 열기](http://127.0.0.1:8792/)로 접속합니다. 다 본 뒤 터미널에서 `Ctrl+C`로 서버를 종료합니다. 포트를 이미 사용 중이면 다른 번호로 바꾸세요. 이미지는 로컬 파일이며, YouTube 영상·Instagram·운영 사이트 링크에는 인터넷 연결이 필요합니다.

## 둘러볼 흐름

- **Story**: 주제 필터, 검색, 결과 없음·초기화, 글 상세, 본문 목차, 이어지는 글.
- **Freediving·Tours**: 소개, 열고 닫는 FAQ, 코론 상세, 문의 화면 연결.
- **Films**: 최신순·첫 화부터 정렬, 작품 상세, 클릭 후 YouTube 플레이어, 이전·다음 화, 전체 에피소드.
- **About**: 소개와 두 활동 영역, 관련 페이지·Instagram 연결.
- **Contact**: 문의 유형 선택, 필수 입력 검사, 이메일 주소 복사, 메일 앱으로 이어지는 초안.
- **공통**: 좁은 화면 메뉴, 키보드 이동·포커스, 메뉴 닫기, 브라우저 뒤로 가기·앞으로 가기.

Contact는 문의를 접수하지 않습니다. 버튼을 누르면 작성 내용을 담은 메일 앱 열기를 요청하며, **메일 앱에서 사람이 직접 보내야 합니다.** 브라우저가 복사·메일 앱을 지원하지 않을 때는 안내와 이메일 주소를 보여줍니다. 입력 내용은 서버·브라우저 저장소에 저장하지 않고, 화면을 떠나면 유지되지 않습니다.

## 실제 자료와 예시의 구분

- **기존 자료 활용**: 이동규/KYU의 공개 역할·연락처·SNS, 제공된 코론 포스터와 일정, 기존 영상의 제목·영상 주소·이미지.
- **시안용 문구**: Story 본문 4개와 소개 문단. 실제 게시글을 복사한 완성 원고나 운영 게시 상태로 보지 않습니다. 코론 Story 제목은 가제입니다.
- **투어 모집 상태**: 기존 안내를 활용한 표시 예시입니다. 실제 잔여 자리·참가 조건·비용을 확정하지 않습니다.
- **운영 기능 미연결**: CMS, 로그인·관리자, 업로드, 검색엔진 설정, DB, 문의 접수·메일 발송 API.
- **이번 시안에서 다루지 않은 영역**: 장비·수강 후기·여행 추천·개인정보 상세·어드민 전체 화면. 개인정보 처리방침 링크는 운영 사이트로 열립니다. 모든 운영 기능의 화면 설계가 끝났다는 뜻은 아닙니다.

참고한 [Kalsentic Stories](https://blog.kalsenlim.com/category/stories/)에서는 이미지 중심의 편집 구성을 참고했습니다. 해당 사이트의 코드·사진·글을 복사하지 않았습니다. 이미지와 글꼴의 출처·고지는 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)에 정리했습니다.

## 검증과 한계

온라인 시안 제작 단계에서 대표 화면 10개를 **390·768·1440px, 총 30개 조합**으로 확인했습니다. 주요 목록·상세 이동과 필터·검색·모바일 메뉴 등을 점검했으며, 해당 화면 검수의 스크린샷 파일은 보관하지 않았습니다. 이 기록을 이미지 증빙이나 운영 앱의 자동화 시험 통과로 대체해서 보지 않습니다.

아래 항목은 별도 검증 또는 결정이 필요합니다.

- 18개 모든 화면·모든 상태의 전 브라우저·실기기 접근성 검사.
- 6개 영상 전체의 외부 플레이어 재생과 브라우저별 메일 앱·클립보드 동작.
- 실제 문의 발송·저장·알림, 운영 데이터 연동, 운영 앱의 공통 검증 게이트.
- 최종 카피, 모집 상태, 메뉴 구성, 새 색상·간격·컴포넌트의 운영 디자인 시스템 반영 여부.

현행 명세와 다른 부분은 운영 반영 전에 다시 설계해야 합니다. 예를 들어 밝은 홈, 별도 Tours 메뉴, 영문 보조 라벨, URL에 저장하지 않는 목록 필터, 메일 앱 연결형 문의는 이번 시안의 표현입니다. 이 파일을 보관하거나 PR을 병합하는 것만으로 운영 명세가 변경되지는 않습니다.
