# Phase 1 문서 변경 이력

`docs/phase1/`의 [PRD.md](PRD.md)와 [CONCEPT.md](CONCEPT.md)는 **하나의 문서 세트로 같은 버전**을 쓴다. 한쪽만 바뀌어도 세트의 버전을 올리고, 두 문서 머리의 버전 표를 함께 갱신한다.

저장소 루트의 `CHANGELOG.md`(웹사이트 변경 이력)와는 별개이며, 충돌을 피하려고 루트 파일은 수정하지 않는다.

**버전 규칙** (`MAJOR.MINOR.PATCH`)
- MAJOR: 범위·구조가 바뀌는 큰 개정 (예: Phase 범위 변경, 사이트 구조 전면 변경). 규강 승인 후 1.0.0
- MINOR: 결정 사항 확정, 섹션 추가, 요구사항 추가·삭제
- PATCH: 오탈자, 표현 다듬기, 링크 수정
- 상태: 초안 → 검토 중 → 확정
