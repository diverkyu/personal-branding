## 1. 한 줄 요약

뼈대(큰 한글 제목, 넓은 여백, 각진 카드, 그림자 없음, 움직임 없음)는 좋다. 문제는 **영문 대문자 보조 라벨·번호·가운데점·↗ 같은 "템플릿 장식"이 모든 화면에 반복되고, 라임이 한 화면에 여러 군데 쓰이는 것**이다. 이 두 가지가 겹치면서 남색 + 라임이 "어두운 배경 + 형광 포인트"라는 흔한 인상으로 읽힌다. 색은 그대로 두고 **라벨을 덜어내고, 라임을 한 곳에만 쓰고, 사진과 한글 타이포를 주인공으로** 세우면 풀린다.

## 4. 남색 + 라임이 "흔한 형광 포인트"로 읽히지 않게

브랜드 색 `#071e29`·`#d6f48a`는 바꾸지 않는다. "어두운 화면 + 형광 초록"이 흔하게 보이는 이유는 색 자체보다 **함께 놓이는 것들**이다: 영문 대문자 라벨, 모노톤 그래픽, 라임이 여기저기 흩어진 버튼과 뱃지. 이 사이트의 주제(물속, 한 호흡, 고요함)에서 끌어낸 방법 네 가지다.

1. **라임은 "숨" 한 번 — 화면당 한 곳.** 라임을 주요 행동 1개 + 현재 위치(메뉴 밑줄)에만 쓴다. 보조 버튼은 테두리(`outline`)나 밑줄 링크로, 장비 카드 행동은 밑줄 링크로, `FINAL CUT` 같은 뱃지는 페이퍼 테두리로. 구분 띠도 라임 면 대신 남색 바탕에 라임 글자(또는 페이퍼 바탕)로 바꾸면 화면에서 가장 큰 라임 면적이 사라진다. 라임이 드물수록 "형광 강조"가 아니라 "물 위로 올라온 빛"처럼 읽힌다.
2. **사진이 남색을 "바다"로 바꾼다.** 같은 남색이라도 옆에 실제 물속 사진(청록 물빛, 햇빛 줄기, 사람의 실루엣)이 있으면 '테크 다크 모드'가 아니라 '수심'으로 읽힌다. 원칙: 사진 위에 라임이나 글자를 얹지 않는다, 그라디언트 덮개를 쓰지 않는다(0.62.0 방향과 같음), **글자가 들어간 이미지는 쓰지 않는다**(아치가 자른다), 가능한 한 규강이 직접 찍거나 찍힌 물속 사진. AI 영상 작품 포스터는 Films 안에서만.
3. **한글 타이포가 목소리.** 형광 인상은 영문 대문자 라벨에서 크게 온다. 영문은 슬로건 한 줄(`Dive deeper. Create beyond.`)과 로고에만 두고, 나머지 위계는 Noto Sans KR 의 크기·굵기 차이와 여백으로 만든다. 이미 있는 큰 한글 제목(H1 72px)이 이 사이트의 가장 고유한 요소다. Lora 이탤릭은 `beyond.`와 서명에만 남겨 "규강의 손글씨" 역할을 지킨다.
4. **배경은 "수심" 순서로, 교차는 적게.** 남색·청록(`--kyu-teal`)·페이퍼를 매 섹션 번갈아 칠하면 템플릿의 줄무늬가 된다. 의미 있는 묶음끼리 같은 배경을 이어 쓰고, 바뀌는 횟수를 줄인다. 예: Freediving 허브는 "투어 + 후기"(페이퍼, 사람의 이야기) → "장비 + 여행"(남색, 물속 준비)처럼 두 덩어리로. 새 색이 아니라 기존 토큰의 배치 문제다.

## 6. 기본 공유 이미지(1200×630) 방향 시안

공통 조건: 1200×630, 핵심 글자는 가운데 약 630×630 안에(카카오톡·일부 메신저가 정사각형으로 자르는 경우 대비), 글자 최소 40px 상당, 기존 토큰 색과 DM Sans·Noto Sans KR·Lora 만 사용, 외부 글꼴 요청 없음. 만드는 방법(빌드 때 `next/og` 로 생성 / 정적 PNG)과 어드민에서 바꿀 수 있게 할지는 시안을 고른 뒤 정한다.

**시안 A — 물속 사진형**
규강이 찍었거나 찍힌 물속 사진을 꽉 채운다. 왼쪽 아래에 페이퍼색 `KYU` 로고와 작은 한 줄 `Dive deeper. Create beyond.`(확정 서식대로 `beyond.`만 라임 Lora 이탤릭). 라임은 그 한 단어뿐. 사진이 말을 다 하므로 가장 "흔하지 않은" 결과. 필요한 것: 사용 허락이 확인된 사진 1장(가로, 어두운 물빛 쪽이 글자 자리).

**시안 B — 한글 타이포형 (사진 없이 바로 가능)**
남색 바탕, 왼쪽 정렬로 한글 헤드라인 "바다에서는 더 깊이, / 상상 속에서는 더 멀리."를 크게(Noto Sans KR 500, 페이퍼색). 아래에 작게 두 줄로 "KYU" / "프리다이빙 강사이자 AI 크리에이터"(가운데점·대시로 잇지 않고). 오른쪽 아래에 파비콘과 같은 **라임 아치 하나**만 둬 앱 아이콘·파비콘과 같은 기호로 묶는다. 사진이 없어도 브랜드가 분명하다.

**시안 C — 아치 창형 (사이트 첫 화면과 같은 구성)**
남색 바탕 오른쪽에 히어로와 같은 아치 모양 창, 그 안에 물속 사진(사진이 없으면 디자인 시스템의 바다 그라디언트 `#8dbdb4 → #267786 → #062432`). 왼쪽에 슬로건 두 줄과 `KYU`. 링크를 누르고 들어왔을 때 첫 화면과 같은 그림이라 이어지는 느낌이 좋다. 다만 정사각형으로 잘리면 아치가 반쯤 잘릴 수 있어 아치를 가운데 쪽으로 당겨야 한다.

추천: 사진이 있으면 A, 공개 일정이 급하면 B 를 먼저 만들고 사진이 생기면 A 로 교체.
