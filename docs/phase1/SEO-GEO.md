PRD **W-4**(SEO: 페이지별 title/description/OG, sitemap, 구조화 데이터)와 **W-5**(GEO: 생성형 검색 노출)를 실제 작업 단위로 나눈 문서다. 출시 순서는 PRD §11 R4(공개 준비)·R6(공개 후 운영)을 따른다.

- **SEO**: 구글·네이버·빙 검색 결과에 정확한 주소·제목·설명으로 나오게 한다.
- **GEO**: ChatGPT·Gemini·Perplexity·네이버 AI 브리핑 같은 생성형 검색이 "프리다이빙 강사 KYU(이동규)는 누구인가", "제주 프리다이빙 투어" 같은 질문에 이 사이트를 **출처로 고르게** 한다. 핵심은 ① 누가 운영하는지 분명한 인물 정보 ② 질문에 바로 답하는 글 ③ 확인 가능한 사실이다.

## 1. 원칙

1. **대표 주소는 하나**: `https://www.diverkyu.com` (SITE_URL). `diverkyu.com`·`http://`·옛 임시 주소(`*.vercel.app`)는 모두 이 주소로 모은다.
2. **화면에 있는 것만** 구조화 데이터에 담는다. 화면에 없는 내용을 검색엔진에만 주지 않는다 (`lib/structured.ts` 규칙).
3. **개인정보·연락처는 구조화 데이터에 넣지 않는다.** 이메일은 화면의 연락 영역에만 있다.
4. **공개 전에는 색인 금지**(noindex, robots `Disallow: /`). 공개 조건(Pro 전환, 처리방침 게시)을 갖춘 뒤 **어드민 사이트 설정 > 검색·공유 > 검색엔진에 노출**을 켠다(0.69.0). 운영 배포·실제 주소에서만 켜지고 프리뷰는 항상 막힌다.
5. 글의 사실·문장은 규강의 것이다. 이 작업은 틀(메타·구조)과 기획 도구를 준비하고, 문구는 규강이 확정한다.

## 3. 정규 주소 규칙 (A, 구현됨)

- 모든 공개 페이지는 `lib/seo.ts`의 `pageMeta(경로, {...})`로 메타를 만든다. 정규 주소는 **자기 경로**이고, 필터(`?status=`·`?tag=` 등)는 붙이지 않는다.
- layout 에는 정규 주소를 두지 않는다. 두면 빠뜨린 페이지가 전부 홈을 가리킨다.
- 공유 미리보기 제목은 `{페이지 제목} — KYU`, 설명은 페이지 설명. 사이트 이름 `KYU`, 언어 `ko_KR`.
- 새 공개 페이지를 만들면 `pageMeta`를 쓴다. E2E가 주요 화면의 정규 주소·사이트 이름을 검사한다.
