# KYU 상표 확인 체크리스트

| 문서 버전 | 최종 수정 | 상태 | 작성 |
| --- | --- | --- | --- |
| **0.42.0** | 2026-11-10 | 초안 (규강 직접 검색 필요) | 규강 + Claude |

변경 이력: [CHANGELOG.md](CHANGELOG.md) · 배경: [CONCEPT §7.8](CONCEPT.md)

> 이 문서는 **직접 검색하고 기록하는 절차**다. 법률 자문이 아니며, 유사 여부의 최종 판단과 출원은 변리사 상담을 권한다. 검색 결과는 아직 없다.

## 1. 왜 확인하나

사이트에서 상품을 판매할 계획이므로, `KYU`라는 이름·로고가 이미 다른 사람의 상표와 같거나 비슷하면 판매 중단이나 분쟁의 위험이 있다. 현재 로고에서 `®`는 뺀 상태다 (등록된 상표에만 쓰는 표시).

## 2. 검색할 곳

| 사이트 | 용도 |
| --- | --- |
| KIPRIS (특허정보검색서비스, kipris.or.kr) | 국내 상표 검색. 무료 |
| 특허로 (patent.go.kr) | 상표 출원 (확인 후) |
| WIPO Global Brand Database | 해외 상표 (해외 판매 계획이 있을 때) |

## 3. 검색어

| 구분 | 검색어 |
| --- | --- |
| 영문 | `KYU` |
| 한글 발음 | 큐, 규, 키유 |
| 유사 철자 | `KYOO`, `KYUU`, `QYU`, `KIU` |
| 도형 | 현재 로고(글자체 로고)를 도형 상표로도 검색 |

유사 여부는 **외관(모양), 호칭(발음), 관념(뜻)** 셋 중 비슷한 것이 있는지로 본다. 철자가 달라도 발음이 같으면 유사로 볼 수 있다.

## 4. 검색할 상품·서비스류

판매하거나 제공할 것에 해당하는 류만 본다. 아래는 예시이며 **류 번호와 범위는 출원 전에 변리사와 확정**한다.

| 우리 활동 | 해당될 수 있는 류 (니스 분류) |
| --- | --- |
| 의류, 모자 등 굿즈 | 25류 |
| 프리다이빙 장비, 스포츠용품 | 28류 (일부 장비는 9류) |
| 온라인 스토어, 상품 판매 | 35류 (소매업, 온라인 판매업) |
| 프리다이빙 강습, 투어 교육 | 41류 (교육, 스포츠 지도) |
| 영상·콘텐츠 제작 | 41류, 9류 |
| 여행·투어 알선 | 39류 |

## 5. 기록 양식

| 검색일 | 검색어 | 류 | 비슷한 상표 (출원인 · 번호) | 상태 (등록/출원/거절/소멸) | 유사 판단 | 메모 |
| --- | --- | --- | --- | --- | --- | --- |
| | | | | | | |

상태가 소멸이나 거절이면 위험이 낮지만, 유효한 등록 상표가 같은 류에 있으면 위험이 높다.

## 6. 결과에 따른 다음 단계

| 결과 | 다음 |
| --- | --- |
| 같거나 비슷한 유효 상표 없음 | 변리사 상담 후 출원 검토. 출원은 먼저 한 사람이 우선(선출원주의) |
| 비슷한 상표가 있음 | 변리사에게 사례를 보여 주고 판단을 받는다. 이름 변경이나 로고 변경을 함께 검토 |
| 같은 류에 같은 상표가 있음 | 해당 류의 판매를 피하거나 이름을 바꾸는 것을 검토 |

## 7. 일정 권고

마켓 상품을 **판매하기 전에** 검색을 마친다. 출원은 심사에 시간이 걸리므로 마켓 개시 일정을 잡기 전에 시작하는 것이 안전하다. 등록이 끝나면 `®`를 다시 붙이고 이 문서와 CONCEPT §7.8을 갱신한다.
