# 한국어 리포트

기준 커밋·환경·실행 시각(KST)·원본 데이터 기준일/시간대·검사 도구 버전·URL 수·실패/생략 범위를 먼저 적는다.

1. 종합 현황: 실측/추정/미확인 구분, 주요 결론.
2. 이전 검사 대비 변화: 같은 URL·규칙·환경으로 비교 가능한 범위만.
3. 치명적인 문제: P0/P1의 실제 근거와 영향. 없으면 없다고 쓰고 미검증을 통과로 바꾸지 않는다.
4. 검색엔진별 상태: 설정/연결/데이터 수집/제출/색인을 각각 구분.
5. 프리다이빙 콘텐츠 SEO: 강사·강습·안전·투어·문의.
6. AI 영상 콘텐츠 SEO: 작품·재생·설명·제작기·작성자·협업.
7. 개선 우선순위: URL, ruleId, 중요도, 근거, 추천 조치, 담당 확인.
8. 권장 코드 수정: 기존 소유 파일·함수와 영향, 중복 구현 금지.
9. 수정 전후 검증: 실행한 명령과 실제 결과, 미실행 항목 별도.
10. 미확인 데이터와 제약: 인증·할당량·작은 표본·스킬/MCP 인식·배포 여부.

Lighthouse 점수와 실제 순위/검색 유입을 같은 점수로 합치지 않는다. 증거 없는 수치나 도구가 반환하지 않은 데이터는 만들지 않는다. 원시 아티팩트는 gitignored 경로에 두고 비밀값 없는 요약만 공유한다.
